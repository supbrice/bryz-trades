# SOFI Levels Card

One-screen daily **close** checklist for SOFI. Beginner-safe.

- Editable levels: get-in, get-out, hard stop (defaults 18.00 / 18.00 / 16.92)
- Order fields: shares planned, limit status, fill price
- Paste today's official close → status updates
- No charts, no other tickers, no buy/sell buttons

Open `index.html` or use GitHub Pages when enabled.

Not financial advice. Does not place orders.
