Ladder

A local trading journal. Not financial advice. Does not place trades or read the market.

Dashboard

Realized figures use closed trades only. Open positions are counts, not profits. This is not account equity.

Positions

Each card is a trade you recorded. A target or hard stop is a plan, not an exit.

What the statuses mean
  • Open — not realized. Still in the journal. Excluded from realized profit and loss.
  • Closed — recorded exit. Uses the exit price, fees, and exit date you entered. Ladder does not check the market.
  • Cancelled — not realized. Excluded from realized profit and loss.

Month

T is closed trades. M is a manual entry. They are never added together. A blank day is unrecorded. $0 is a recorded flat. Adj is an account adjustment, not trading P/L.

Analytics

Every metric below uses the same closed trades: a recorded exit price, quantity, and exit date in the range. Open trades are not estimates of profit.

Settings and backup

Backup

The file stays on this device unless you move it yourself. Ladder does not upload it.

Restore

Import checks the file before it changes anything. Merge keeps this journal and adds what is new. Replace swaps in the file after a backup is stored here. Matching trade ids are not counted twice.

Risk calculator

Optional planning math from the numbers you type. It is not financial advice and does not place an order. Actual losses can exceed the planned risk because of gaps, slippage, fees, and execution.

How saving works

The journal is stored in this browser’s local storage on this device. It is not an account, and it is not sent to a server.

Another browser, another device, or a private-browsing window has its own empty copy. Private browsing may delete the journal when the window closes.

Clearing site data, cookies, or history for this site deletes the journal. Export a JSON backup first if the records matter.

A failed save or a failed import leaves the previous copy in place. Before an upgrade or import, Ladder also keeps a backup copy in this browser.

Schema version 2.

Saved on this device. Export a backup before you clear site data. No live prices, and nothing here buys or sells.

Add trade

Profit and loss uses entry price when both prices are filled. If entry price is blank, average cost is used. Long return divides by shares × that price. Short return divides by the sale proceeds, shares × that price, not by margin.

The closing price is the exit you write down. Choosing a target or stop reason does not mean the market reached that level.

Levels checklist

Optional, and only a comparison with a close you paste. Hard stop is checked before get-out. A close equal to a level is not under it. This does not place or cancel orders.

Checklist

Day

Closed trades and manual entries stay on separate lines. Ladder does not add them together.

Manual entry

A hand-typed day result from before trade-level tracking, or an account note you want to keep. It is labeled manual and is not a closed trade.

Split the manual entry

This split only describes the manual amount. It is not added to realized P/L.

Account adjustment

A deposit, withdrawal, or other account change. It is not trading profit or loss and is not added to either total.
